# 온비드 · 신탁사 · 대한민국 법원경매 통합 대시보드

전국 온비드 실시간 공매 매물, 14개 주요 부동산 신탁사 PF 사업장 및 대한민국 법원경매(대법원 경매정보) 전국 실시간 물건을 전수 수집·통합하여 조건(면적, 금액, 지역, 용도지역 등)에 맞는 개발부지를 탐색하고 전문 엑셀 파일로 추출하는 Streamlit 기반 대시보드입니다.

---

## 🚀 주요 기능

1. **3대 경·공매 데이터 통합 수집 & 지번 기반 중복 제거 (2,100+ 건)**
   - **온비드 실시간 공매**: 공공데이터포털 전자자산처분 OpenAPI 연동
   - **14대 신탁사 PF 사업장**: 무궁화·우리·대신·한토신·한자신·한투부·대토신·코리아·신영·하나·신한·KB·교보·코람코 자산신탁 전수 취합
   - **대법원 법원경매정보 전국 실시간**: 100억 이상 대형 물건 및 500평 이상 개발부지 전국 전수 수집
   - **주소 정규화 기반 대조**: 시도 및 읍/면/동/지번 번지 정규화로 중복 매물 자동 매칭

2. **조건별 스마트 필터링**
   - **매물 출처 선택**: [전체], [신탁사 공매만], [법원경매만], [온비드 일반공매만]
   - **진행상태 구분**: 진행중만 / 마감만 / 유찰 수의계약 협의가능
   - **낙찰/취하 매물 자동 제외**: 이미 매각되었거나 취하된 물건 자동 필터
   - **전국 17개 시/도 & 시/군/구 연동**: 2단계 지역 필터
   - **용도지역 다중 선택**: 일반주거, 준주거, 상업, 준공업, 자연녹지 등 복수 선택
   - **면적 & 최초입찰가 범위**: 평수 및 감정가(억 원 단위) 최소/최대 설정

3. **원클릭 공식 사이트 연동 & 간편 복사**
   - **신탁사 공매**: 해당 신탁사 공식 공매게시판으로 100% 직행
   - **법원경매**: 대한민국 법원경매정보 검색 화면 연결 + 관할법원 & 사건번호 원클릭 복사
   - **온비드 공매**: 온비드 공식 통합검색 화면 연결

4. **전문 엑셀(.xlsx) 보고서 추출**
   - 필터링된 검색 결과를 관할법원, 사건번호, 마감일, 하이퍼링크 등이 포함된 전문 서식으로 즉시 다운로드

---

## 💻 로컬 실행 방법

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 대시보드 실행
streamlit run app.py
```
